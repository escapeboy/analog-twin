# Use of AI

**Building the project.** Claude Code (Anthropic) wrote the code and the documentation drafts, working from a written
specification and under the direction of the project owner, who made the design decisions, reviewed the results and
recorded deviations in `docs/build-log.md`. Several Claude Code agents worked in parallel on separate parts (terrain
index, light model, AI crew, web app, trajectory, site finder, documentation).

**In the product.** The campaign planner uses LLM agents through the Claude Code CLI (`claude -p`): four specialists
(terrain, lighting, logistics, test lead) and a director. They interpret and disagree; they do not calculate. All
numeric outputs are computed by deterministic code. The agents receive an evidence pack, every claim must cite an
evidence reference from that pack, and any claim with a missing reference, or a number not found in the cited evidence,
is removed. Numeric fields of the final plan are overwritten from the evidence. If the CLI is unavailable the app plays
back a recorded session and says so.

**What AI did not do.** No dataset was generated by AI. Coordinates, constants and results are taken from cited
sources or computed by code. Where a value is not cited or computed, it is not in the project.

**Checks.** The repository has automated tests for the light model, terrain features, site finder, trajectory engine,
API and crew validation. All numbers in the documentation come from `docs/metrics.json`.
