# Data attribution

Data files are not stored in git. This page lists every dataset and software component the project uses, where it
comes from, and what its provider says about use. Licence entries were read from the provider's page on 2026-11-14.
Where a page did not state a licence, the entry says so; "(not verified)" means we could not confirm the terms, not
that there are none.

## Reference used for a threshold

The NDVI threshold for "barren" comes from NASA Earth Observatory, "Measuring Vegetation (NDVI & EVI)", https://earthobservatory.nasa.gov/features/MeasuringVegetation/measuring_vegetation_2.php: "Very low values of NDVI (0.1 and below) correspond to barren areas of rock, sand, or snow. Moderate values represent shrub and grassland (0.2 to 0.3)." Quoted as reported by W1; we did not re-fetch the page.

## Coordinates

Target, analog-site, landing-region and launch-pad coordinates, each with its source URL, are in
[sources.md](sources.md). The main sources are the NASA Lunar Surface Data Book (NASA/TP-20250002845), the USGS
Gazetteer of Planetary Nomenclature and NASA's Artemis III region announcements. Some analog sites carry
coordinates from Wikipedia where no primary source was reachable; sources.md marks each case.
